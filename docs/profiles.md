# profiles

Mock user profiles at `/profile/[handle]`. UI-only: no backend, no persistence.

- Route: `app/profile/[handle]/page.tsx` (server). URL is the handle without `@` (`/profile/ren.eth`); looks up `@${handle}` via `getProfile()`, `notFound()` for unknown handles (`:12`). Renders `ProfileView` + `FeedSidebar` in `.feed-shell`.
- Data: `app/lib/mockProfiles.ts` — `PROFILES` (`:20`, name/rank/bio/joined/followers/following; rank matches the author's feed posts), `profileHref()` (`:39`, undefined when no profile → callers render plain text), `profileActivity()` (`:49`) derives tabs from feed mocks: omens = their `GLOBAL_POSTS`+`EXCLUSIVE_POSTS` (rank overridden with the profile's), comments = their `POST_REPLIES` entries paired with the parent post, trades = omens that carry a `call`.
- Portfolios: `app/lib/mockPortfolios.ts` `PORTFOLIOS` — static 24h-session snapshots shaped like [portfolio.md](portfolio.md) (Base meme coins, spot or 1/2/3/5× lots). Kept out of `mockProfiles.ts` because `PostCard` (client) imports `profileHref` from there.
- Rank gate: `canViewPortfolio()` (`app/lib/rank.ts:42`) — viewer ≥ profile rank. `rankScore()` (`:30`): tier × 10 + division, tiers bronze < silver < gold < diamond < oracle, divisions count up (Gold I < Gold II < Gold III), bare tier ("Oracle") sorts below its divisions. Viewer is hardcoded `VIEWER_RANK = "Gold II"` (`:39`).
- Gate runs on the server (`page.tsx:15`): a locked portfolio is passed as `null`, so its data never reaches the client; `LockedPortfolio` (`ProfileView.tsx:199`) shows blurred empty placeholder rows, required rank vs viewer rank badges, and a `/duel` CTA.
- `app/profile/[handle]/ProfileView.tsx` (client): hero = avatar (tier ring/glow via `data-rank`) → large `RankBadge` overlapping the avatar's bottom edge (`.profile-rank` gives it an opaque backing) → name/handle → bio → Joined · Followers · Following → Follow toggle (local only; initial state from `FOLLOWED_HANDLES`, follower count ±1). Tabs in order Omens / Comments / Trades / Portfolio (`:16`, `useState`, resets on reload; Portfolio shows `LockIcon` when locked). Trades tab reuses `MarketCallCard` (one-row layout at this width) with a fulfilled/broken/liquidated/open summary from `callTrack()` state.
- Shared: `app/RankBadge.tsx` (badge with own `data-rank`, `size="lg"`), `app/AuthorLink.tsx` (name → profile link), `app/lib/avatar.ts` (`hueFromHandle`/`avatarGradient`, moved out of `PostCard`).
- CSS: `.author-link`, `.rank-badge--lg`, `.profile-hero`/`.profile-avatar`/`.profile-rank`/`.profile-identity`/`.profile-bio`/`.profile-stats`/`.profile-follow`, `.profile-tabs` (4-col grid ≤768px), `.profile-comment*`, `.profile-trade*`, `.profile-portfolio*`/`.profile-lot*`/`.profile-pnl`, `.profile-locked*` (card stacked over preview with `grid-area: 1/1`; card needs `z-index` because the preview's filter/opacity lifts it into its own layer) in `app/globals.css`.
- Not built: see [roadmap.md](roadmap.md) "Real profiles".
