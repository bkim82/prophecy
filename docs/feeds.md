# feeds

Twitter-styled social feeds. UI-only pass: no backend, no persistence; the composer posts locally only.

- Routes: `/` = Global feed (`app/page.tsx`), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`, no longer linked from the header nav), `/sanctum` = Oracle Room live Pulse room (`app/sanctum/page.tsx`, see [sanctum.md](sanctum.md)), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)).
- Desktop header (`app/layout.tsx`) is a 64px, 3-column grid: brand | `app/TabNav.tsx` | `.header-actions` (`app/BalancePill.tsx` + `app/AccountMenu.tsx`). `.app-header-inner` uses the page shells' width rule (`min(100% - 56px, --shell-max)`) so header edges align with content.
- `app/TabNav.tsx` — desktop `Omens`/`Arena`/`Sanctum`/`Wallet` (same order/icons as `app/MobileBottomNav.tsx`), active via `usePathname()` (exact on `/`, prefix otherwise), active = teal text + `--brand` 12% background. 769–1000px drops the icons.
- `app/BalancePill.tsx` — signed-in only; ember icon + Embers count button, dropdown (`.balance-menu-popover`) lists Embers + wallet USD + link to `/wallet`.
- `app/AccountMenu.tsx` — signed in: Clerk `UserButton` with a Light/Dark mode `UserButton.Action` (`useTheme()` from `app/ThemeToggle.tsx`); signed out: standalone `ThemeToggle` + Sign in. `compact` prop = mobile avatar-style sign-in.
- `app/MobileBottomNav.tsx` replaces the header nav at or below 768px; the compact mobile header keeps brand, `BalancePill`, `AccountMenu compact`.
- `app/PostCard.tsx` — client component; flat row: avatar → meta (`AuthorLink` name, `RankBadge` right after it, `@handle · time`, then right-aligned flair tag + `PostMenu` ⋯) → content → image / `MarketCallCard` → actions. Author name (`app/AuthorLink.tsx`) and avatar (`:356`, mouse-only duplicate: `tabIndex=-1`, `aria-hidden`) link to `/profile/[handle]` when `profileHref()` finds a mock profile, see [profiles.md](profiles.md). Every row has `id="post-<id>"` (call-strip anchors). Branches on `Post.kind`: `"streak"` banner row, `"promo"` quiet system line, `"clash"` → `ClashCard` (`:292`: eyebrow with `ClashIcon` + total votes, `Nova ↑ 69.5k vs ↓ 67.6k Vesper`, crowd split bar, two "Side with …" buttons; voting adds one local vote to that side and recomputes split/bar/total, the pressed side reads "✓ Sided with …", click again to switch or take it back — nothing persists or settles), else the standard row. Flair = short tag (`FLAIRS` `:29`: For you / Hot / Rising / Followed, full sentence as `title`). Actions row: reply `↩` (toggles the inline `ReplyThread`), repost `⟲` and like `♡` (local optimistic toggles, nothing persists), counts compact (`1.3k`).
- `MarketCallCard` (`app/PostCard.tsx:132`, exported for the profile Trades tab) — every call on one doom → destiny track. Pieces: `TimeRing` (`:64`, coin inside a ring that drains `expiresIn / windowMin`; full once resolved) │ asset + `↑LONG`/`↓SHORT` over `20x · 1h 55m left` / `closed` / `wiped` │ `CallTrackBar` (`:89`: left end = doom = whichever of `stop` / leverage liquidation price sits closer to entry, labelled `STOP`/`LIQ`; right end ✦ = `target`; glowing orb = current price; tick = cast/entry; the segment between tick and orb is the move so far) │ ROI hero (`callRoi()` = price move × leverage, flipped for shorts, floored at −100%) with a status label (`STATUS_LABEL` `:120`) │ open calls only: violet Copy (zigzag `TrendIcon`, not wired) with `TailingCount` under it (3 overlapping gradient circles + `18.4k tailing` from `copiedBy`). State comes from `callTrack()` (`app/lib/calls.ts:58`) and is set as `data-state`: `live` (violet glow, pulsing orb), `doom` (open with the orb in the first 15% of track, `DOOM_ZONE` `:32` — red pulse, "⚠ 0.3% to liq/stop"), `fulfilled` (`outcome.status "won"`, orb on ✦, all gold), `broken` (`"lost"`/`"close"`, grayscale + dimmed), `liquidated` (`"liquidated"`, red hazard stripes, −100%). Layout is a container query on `.market-call-frame`: ≥680px one row (profile Trades tab), default = track on its own row (feed), ≤420px adds an action row and lets the CAST label flow inline (phones). Prices format like the entry string (`formatCallPrice`).
- `app/FeedSwitcher.tsx` — client component on `/` only; renders the `.feed-nav` rail + `.feed-main` (Topics dropdown in `.feed-heading`, then one `.feed-panel`: `app/FeedComposer.tsx` → `app/CallStrip.tsx` → `.feed-list`). Rail filters (text only, `◆ Feeds` label): For You / Following (`FOLLOWED_HANDLES`) / Live Calls (`kind === "call"`, green dot + `LIVE_CALL_COUNT`) / Clashes (`kind === "clash"`), combined with the community dropdown (`All`/`BTC`/`ETH`/`DOGE`, trigger reads `Topics` while `All`, blur-to-close, matches `post.market ?? post.call?.market`). `localPosts` state (`:32`) holds composer posts, prepended to the feed. No persistence, resets on reload. ≤960px the rail becomes a horizontally scrolling pill row under the heading (`.feed-main` gets `display: contents` + `order`).
- `app/FeedComposer.tsx` — local-only composer: initial avatar, "What's the market telling you?" input (280 max), `+ Trade` → `/duel`, violet Post (disabled while empty) prepends a `kind: "text"` post authored by the Clerk user's first name/username (else "You"/`@you`). `app/CallStrip.tsx` — story-style chips for the calls in the visible feed (avatar ringed green/red by ROI, market, ROI), each an `#post-<id>` anchor.
- `app/FeedSidebar.tsx` — persistent right rail (`Leaderboard` / `Most Profitable Calls` / `Trending Prophecie`), rendered on both `/` and `/exclusive` via the `.feed-shell` two-column grid; reads `app/lib/sidebarMocks.ts` (`LIVE_ARENAS`/`TRENDING_CALLS` are still independent mock data, but `TRENDING_PROPHECIES` pulls real entries out of `mockPosts.ts`'s `GLOBAL_POSTS` by id (`TRENDING_PROPHECY_IDS`) so "Trending Prophecie" shows actual post content instead of a synthetic leaderboard).
- `app/lib/mockPosts.ts` — hardcoded `GLOBAL_POSTS`/`EXCLUSIVE_POSTS` arrays, no database table. `Post.call`/`.rank`/`.kind`/`.streakStat`/`.image`/`.market` are display-only fields with no backing computation — `PostImage` (`"chart"` sparkline or `"meme"` gradient+emoji tile, rendered by the `PostImage` component in `app/PostCard.tsx`) is placeholder art standing in for a real image upload. `Post.market` is a manually-tagged community label used only by non-`call` posts (e.g. `g7`, `g8`, `g-streak1`) — a `call` post's community is implied by `call.market` instead; both feed `FeedSwitcher`'s community dropdown. `FOLLOWED_HANDLES` backs the `FeedSwitcher` "Following" filter only, not a real social graph. The `g-streak1` mock post now reads as a daily BTC-call streak (consecutive-day count) rather than a same-day win streak — no daily-prediction mechanic backs it (see [roadmap.md](roadmap.md) "Not built"). `Post.flair` (`forYou`/`engaging`/`copying`/`followed`) and `MarketCall.copiedBy` are hand-assigned display-only fields — no engagement/recommendation signal or copy-trade action backs them; `copiedBy` is picked to scale with rank (Oracle `g-oracle1` 18.4k, Diamond `g-diamond1` 7.2k). `POST_REPLIES: Record<Post['id'], Reply[]>` backs `app/PostCard.tsx`'s reply thread — hand-written, not derived from `Post.replies` (that count is still just decorative), covers most non-streak/promo posts; posts without an entry render the thread's empty state. `Post.reposts` is a display-only count. `kind: "clash"` posts carry `Post.clash` (`Clash`/`ClashSide` `:58`, two sides with hand-picked crowd `share`s); `g-clash1` is the only one. `LIVE_CALL_COUNT` (`:92`) is a hardcoded rail number, not derived. `n1`–`n6` are trade-free opinion posts on generic market news (rate decision, exchange outage, ETF flows, stablecoin supply, Pulse, bridge exploit) interleaved with the calls; `n1`/`n2`/`n4` have `POST_REPLIES` threads. `MarketCall` carries `target`, optional `stop`, and `windowMin` (live calls) for the track/ring; ROI is derived from `entryPrice`/`currentPrice` (no `changePct`/`spark` on calls any more). `ClashSide.votes` replaces the old `share`. `GLOBAL_POSTS` is hand-ordered for a mixed top (trade → gossip → trade → clash → gossip → trade → news …) and re-timestamped to match; `gs1`–`gs5` are gossip/opinion posts, `t-near`/`t-liq`/`t-broken` are example doom / liquidated / broken calls, `g-clash2` a second (ETH) clash.
- `app/lib/rank.ts` — hardcoded `MOCK_CURRENT_RANK`/`MOCK_RANK_THRESHOLD` stub with `isExclusiveUnlocked()`, but `app/exclusive/page.tsx` doesn't call it right now — the gate (locked teaser + blurred preview) is temporarily disabled while iterating on the feed look, so `/exclusive` always renders the real list. No rank system exists anywhere else in the app (see [roadmap.md](roadmap.md) "Not built") — `Post.rank` strings in mock data are unrelated hardcoded labels, not derived from this stub.
- `PostCard` splits blank-line-separated text content into separate paragraphs for long-form takes. Content over 220 chars starts collapsed (`.post-content.is-collapsed`: 5 lines at every width, 7 at ≤768px) with a `.post-read-more` Read more/Show less toggle.
- Identity: mock posts use plain strings, not wired to Clerk. A future posting pass should use Clerk identity for authorship (persistent visible name/handle), not the anonymous `app/lib/playerId.ts` id used for matchmaking.
- Layout: `.feed-shell` is a two-column grid (`app/globals.css`) — feed column + sticky `.feed-sidebar`; `/` adds `.feed-shell--nav` for a three-column `200px | feed | 340px` grid (`180px | feed | 280px` at 961–1180px) with the `.feed-nav` rail, max width `var(--shell-max)` (1220px, shared with `.app-header`/`.lobby-shell`/`.wallet-shell`), collapsing to one column under 960px. Posts are flat rows inside one bordered `.feed-panel` (hairline `border-top` between rows, `.feed-list > * + *`), also used for `/exclusive` and the profile Omens tab; `.feed-panel`/`.feed-nav` set `min-width: 0` so the scrolling chip/pill rows can't widen the grid column on phones. On phones, the shell uses 16px page gutters and leaves room for the fixed safe-area-aware bottom nav.
- CSS: `.main-nav`/`.main-nav-link`/`.main-nav-icon`, `.balance-menu`/`.balance-display`/`.balance-menu-popover`, `.account-signed-out`, `.desktop-header-content`/`.mobile-header-content`/`.mobile-bottom-nav`, `.feed-shell`/`.feed-main`/`.feed-sidebar`/`.feed-heading-row`/`.community-dropdown`/`.community-dropdown-trigger`/`.community-dropdown-menu`/`.feed-tabs`/`.feed-shell--nav`/`.feed-nav`/`.feed-nav-label`/`.feed-nav-icon`/`.feed-list`/`.post-card`/`.post-read-more`, `.market-call`/`.call-spark`/`.call-outcome`/`.call-expiry`, `.post-image`/`.post-image--chart`/`.post-image--meme`, `.post-card--streak`/`.post-card--promo`, `.rank-badge`/`.post-meta-trail`/`.post-menu`/`.post-menu-trigger`/`.post-menu-dropdown`/`.post-actions`/`.action-reply`/`.action-reply-caret`, `.reply-thread`/`.reply-thread-empty`/`.reply-item`/`.reply-avatar`/`.reply-body`/`.reply-meta`/`.reply-content`/`.reply-actions`/`.reply-thread-more`, `.sidebar-panel`/`.sidebar-row`, `.locked-teaser`/`.locked-preview` in `app/globals.css`, all resolving through the existing theme CSS variables. `PostCard` sets `data-rank` on the card (`rankTier()` in `app/lib/rank.ts:25`: first word of `Post.rank`), and the Rooms tier tokens (`--room`/`--room-strong`/`--room-glow`) key off `data-rank` as well as `data-room`, so outlines + `.rank-badge` take the tier color. Rows have no rank outline/glow: Gold/Diamond get a tier avatar ring, Oracle a ring + glow; the trade card border shows call state, not rank. Gold+ `.rank-badge`s are animated: metallic fill + a `rank-sheen` sweep (`::after`, z-index -1 inside the isolated badge so it passes behind the text; 3.6s Gold / 2.8s Diamond / 2.4s Oracle), Diamond's `◆` twinkles, Oracle's fill drifts (`rank-holo`) with a pulsing glow and a spinning `✦`. Badges render through `app/RankBadge.tsx`, which puts `data-rank` on the badge itself (badge CSS is `.rank-badge[data-rank=…]`, not scoped to `.post-card`, so it also works on `/profile`; base `.rank-badge` is `inline-block` so `overflow: hidden` clips the sheen inline too) and sets `--shine-delay` from `hueFromHandle` (`app/lib/avatar.ts`) so same-tier sweeps don't sync. All of it stops under `prefers-reduced-motion`. `.market-call` (and `.post-image--chart`'s fill) use `--hud-*`. `.rank-badge` is a small uppercase mono tag (4px radius). New: `.feed-panel`, `.feed-composer*`, `.call-strip`/`.call-chip*` (`--ring`), `.post-tag*`, `.action-repost`, `.market-call-frame` (size container), `.market-call[data-state]`/`[data-dir]` (`--tone`/`--accent`/`--edge`), `.call-ring*`, `.market-call-name`/`-asset`/`-terms`/`-roi`/`-status`, `.call-side`, `.call-track*` (rail/fill/cast/orb/destiny/labels), `.market-call-action`/`.market-call-copy-icon`/`.market-call-tailing`/`.copier-stack` (`--gold` token, both themes), `.clash-*` (incl. `.clash-votes`), `.feed-nav-live`.
