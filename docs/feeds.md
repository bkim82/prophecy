# feeds

Twitter-styled social feeds. Mock content is static; omens from both composers (inline + `/compose`) are saved in Postgres and shown above it — see [posts.md](posts.md).

- Routes: `/` = Global feed (`app/page.tsx`), `/post/[id]` = single post + replies (`app/post/[id]/page.tsx`, mock ids first, then saved posts; 404 for unknown ids), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`, no longer linked from the header nav), `/sanctum` = Oracle Room live Pulse room (`app/sanctum/page.tsx`, see [sanctum.md](sanctum.md)), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)), `/compose` = full-page composer (`app/compose/page.tsx`, below).

Phone header (≤768px) fits the bell by dropping the balance caret, 6px gaps, a smaller wordmark at ≤420px/≤380px (34px theme/bell buttons at ≤380px), and a shrinkable `.brand` so a long balance never pushes the avatar off-screen. `.app-header-inner` uses the page shells' width rule (`min(100% - 56px, --shell-max)`) so header edges align with content.

- Inference algorithm (`app/lib/topicInterest.ts`, tests `lib/topicInterest.test.ts`): `SIGNAL_WEIGHTS` (`:13`) view_topic 1 / open_post 1 / like 2 / repost (incl. vouch/defy) 3 / reply 3 / bookmark 3 / own post 4, each credited to every topic of the post; score = Σ weight × 0.5^(age/`HALF_LIFE_DAYS` 14d), signals older than `WINDOW_DAYS` (60) ignored; inferred when score ≥ `INFER_AT` (5) from ≥ `MIN_SOURCES` (2) distinct posts/visits, not followed, not muted; top `MAX_INFERRED` (4) by score (`inferInterests` `:66`). ≈ 3 likes or 2 bookmarks in a few days, 5 topic visits, or a mix; 2 likes or one heavily-engaged post isn't enough.
