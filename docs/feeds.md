# feeds

Twitter-styled social feeds. UI-only pass: no backend, no persistence; the composer posts locally only.

- Routes: `/` = Global feed (`app/page.tsx`), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`, no longer linked from the header nav), `/sanctum` = Oracle Room live Pulse room (`app/sanctum/page.tsx`, see [sanctum.md](sanctum.md)), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)).
- Desktop header (`app/layout.tsx`) is a 64px, 3-column grid: brand | `app/TabNav.tsx` | `.header-actions` (`app/ThemeToggle.tsx` + `app/BalancePill.tsx` + `app/AccountMenu.tsx`). `.app-header-inner` uses the page shells' width rule (`min(100% - 56px, --shell-max)`) so header edges align with content.
- `app/TabNav.tsx` — desktop `Omens`/`Arena`/`Sanctum`/`Wallet` (same order/icons as `app/MobileBottomNav.tsx`), active via `usePathname()` (exact on `/`, prefix otherwise), active = teal text + `--brand` 12% background. 769–1000px drops the icons.
- `app/BalancePill.tsx` — signed-in only; ember icon + Embers count button, dropdown (`.balance-menu-popover`) lists Embers + wallet USD + link to `/wallet`.
- `app/ThemeToggle.tsx` — top-right theme picker, signed in or out, desktop + mobile headers: swatch button → `.theme-menu-popover` with Obsidian (default, black + violet) / Navy (the original navy + teal feed) / Moonstone (light: pearl surfaces, white header, violet brand; id `light`) (`THEMES` in `app/theme.ts`). The old warm-sand light theme is gone. See [architecture.md](architecture.md) Theming.
- `app/AccountMenu.tsx` — signed in: plain Clerk `UserButton` (no theme action); signed out: Sign in. `compact` prop = mobile avatar-style sign-in.
- `app/MobileBottomNav.tsx` replaces the header nav at or below 768px; the compact mobile header keeps brand, `ThemeToggle`, `BalancePill`, `AccountMenu compact`.
- `app/PostCard.tsx` — client component; flat row: avatar → meta (`AuthorLink` name, `RankBadge` right after it, `@handle · time`, then right-aligned flair tag + `PostMenu` ⋯) → content → image / `MarketCallCard` → actions. Author name (`app/AuthorLink.tsx`) and avatar (`:369`, mouse-only duplicate: `tabIndex=-1`, `aria-hidden`) link to `/profile/[handle]` when `profileHref()` finds a mock profile, see [profiles.md](profiles.md). Every row has `id="post-<id>"` (call-strip anchors) and `data-post-id` (rail view tracking + Recently viewed jump target). Branches on `Post.kind`: `"streak"` banner row, `"promo"` quiet system line, `"clash"` → `ClashCard` (`:293`: eyebrow with `ClashIcon` + total votes, `Nova ↑ 69.5k vs ↓ 67.6k Vesper`, crowd split bar, two "Side with …" buttons; voting adds one local vote to that side and recomputes split/bar/total, the pressed side reads "✓ Sided with …", click again to switch or take it back — nothing persists or settles), else the standard row. Flair = short tag (`FLAIRS` `:30`: For you / Hot / Rising / Followed, full sentence as `title`). Actions row: reply `↩` (toggles the inline `ReplyThread`), repost `⟲` and like `♡` (local optimistic toggles, nothing persists), counts compact (`1.3k`), then a right-aligned `.action-bookmark` toggle (`BookmarkIcon`, filled when saved; persisted via `app/lib/postLists.ts`).
- `MarketCallCard` (`app/PostCard.tsx:133`, exported for the profile Trades tab) — every call on one doom → destiny track. Pieces: `TimeRing` (`:65`, coin inside a ring that drains `expiresIn / windowMin`; full once resolved) │ asset + `↑LONG`/`↓SHORT` over `20x · 1h 55m left` / `closed` / `wiped` │ `CallTrackBar` (`:90`: left end = doom = whichever of `stop` / leverage liquidation price sits closer to entry, labelled `STOP`/`LIQ`; right end ✦ = `target`; glowing orb = current price; tick = cast/entry; the segment between tick and orb is the move so far) │ ROI hero (`callRoi()` = price move × leverage, flipped for shorts, floored at −100%) with a status label (`STATUS_LABEL` `:121`) │ open calls only: violet Copy (zigzag `TrendIcon`, not wired) with `TailingCount` under it (3 overlapping gradient circles + `18.4k tailing` from `copiedBy`). State comes from `callTrack()` (`app/lib/calls.ts:58`) and is set as `data-state`: `live` (violet glow, pulsing orb), `doom` (open with the orb in the first 15% of track, `DOOM_ZONE` `app/lib/calls.ts:32` — red pulse, "⚠ 0.3% to liq/stop"), `fulfilled` (`outcome.status "won"`, orb on ✦, all gold), `broken` (`"lost"`/`"close"`, grayscale + dimmed), `liquidated` (`"liquidated"`, red hazard stripes, −100%). Layout is a container query on `.market-call-frame`: ≥680px one row (profile Trades tab), default = track on its own row (feed), ≤420px adds an action row and lets the CAST label flow inline (phones). Prices format like the entry string (`formatCallPrice`).
- `app/FeedSwitcher.tsx` — client component on `/` only; renders the `.feed-nav` rail + `.feed-main` (Topics dropdown in `.feed-heading`, then one `.feed-panel`: `app/FeedComposer.tsx` → `app/CallStrip.tsx` → `.feed-list`). Rail filters (text only, `◆ Feeds` label): For You / Following (`FOLLOWED_HANDLES`) / Live Calls (`kind === "call"`, green dot + `LIVE_CALL_COUNT`) / Clashes (`kind === "clash"`) / Bookmarked (ids in `useBookmarks()`, feed order, own empty-state copy), combined with the community dropdown (`All`/`BTC`/`ETH`/`DOGE`, trigger reads `Topics` while `All`, blur-to-close, matches `post.market ?? post.call?.market`). `localPosts` state (`:40`) holds composer posts, prepended to the feed. Under the tabs, a border-top section break then `.feed-recent` "Recently viewed" (rail-only, hidden ≤960px): up to 5 posts from `useRecentlyViewed()` (avatar + author + one-line snippet, most recent first) and a `Clear` button; a post is marked viewed by an `IntersectionObserver` on `.feed-list [data-post-id]` once ≥50% visible (or filling half the viewport) for `VIEW_DWELL_MS` (1s); clicking a row runs `jumpToPost` — resets to For You/All via `flushSync` if the current view hides it, scrolls it to center, and adds `.is-flash` (one-shot inset `post-flash` outline). Composer posts, filter and community selection aren't persisted, reset on reload. ≤960px the rail becomes a horizontally scrolling pill row under the heading (`.feed-main` gets `display: contents` + `order`).
- `app/FeedComposer.tsx` — local-only composer: initial avatar, "What's the market telling you?" input (280 max), `+ Trade` → `/duel`, violet Post (disabled while empty) prepends a `kind: "text"` post authored by the Clerk user's first name/username (else "You"/`@you`). `app/CallStrip.tsx` — story-style chips for the calls in the visible feed (avatar ringed green/red by ROI, market, ROI), each an `#post-<id>` anchor.
- `app/lib/postLists.ts` — per-browser localStorage id lists (`omens-bookmarks-v1`, `omens-recent-v1`, cross-tab via `storage` event), same `useSyncExternalStore` pattern as `app/duel/portfolio/watchlist.ts`: `useBookmarks()` (`ids`/`has`/`toggle`, newest first), `useRecentlyViewed()` (`ids`/`clear`), `markViewed(id)` (moves to front, capped at 5). Not tied to Clerk identity. `/exclusive` cards also show the bookmark toggle, but the rail only resolves ids against `GLOBAL_POSTS`, so exclusive bookmarks don't surface in `Bookmarked`. The old "N online · N arenas live" pulse strip (`LIVE_PLAYER_COUNT`/`LIVE_DUEL_COUNT`) was removed from `app/page.tsx` in favor of the community dropdown.
- `app/FeedSidebar.tsx` — persistent right rail (`The Oracles` / `Most Profitable Calls` / `Live in the Arena`), rendered on both `/` and `/exclusive` via the `.feed-shell` two-column grid; reads independent mock data from `app/lib/sidebarMocks.ts` (`TOP_TRADERS`/`PROFITABLE_CALLS`/`LIVE_ARENAS`). `Most Profitable Calls` is the client component `app/ProfitableCallsPanel.tsx` (`.sidebar-panel--calls`): `1H`/`24H`/`7D` tabs (local `useState`, default `24H`) pick a `PROFITABLE_CALLS` window; rows rank by ROI (`changePct × leverage`, flipped for shorts), top 3, unnumbered: market glyph + `BTC ↑ LONG` and the ROI lead each row, `leverage× · handle` on the second line. `Live in the Arena` is the client component `app/LiveArenaPanel.tsx` (`.sidebar-panel--arena`): `LIVE_ARENAS` duels, each with a bold `.sidebar-arena-rank` circle in its tier's colour (`data-rank` = `LiveArena.tier`) + mono timer counting down 1/s from the mock value (wall-clock based); at 0:00 a duel restarts at `ARENA_ROUND_SECONDS` (90s); ≤ `ARENA_URGENT_SECONDS` (10s) gets `.is-urgent` (red).
- `app/OraclesLeaderboard.tsx` — client component; the first rail panel, "The Oracles", as a tarot spread. Header has a `24H`/`7D`/`ALL` toggle (`useState`, default `7d`) over `TOP_TRADERS[period]` (`app/lib/sidebarMocks.ts`: hand-ordered per period, rank = position; `TopTrader` = handle + `tier` label + `winRate`). Ranks I–III are podium cards (DOM order I/II/III, CSS `order` lays out II · I · III, rank I taller) with Roman numeral, avatar initial in a win-rate ring (green arc = `winRate`, rest red) over a sunburst, handle, tier footer; ranks IV–VII are rows (Roman rank, ringed avatar, handle, tier). No score/percentage shown. `Full leaderboard` button expands the list inline to all 10 mock traders (no separate page); switching period collapses it. Animation (CSS only, off under `prefers-reduced-motion`): cards rise face-down and flip III → II → I, rank I flares, a light cone opens over it, its sheen sweeps and aura pulses; rays spin, corner ✦ twinkle, embers rise, cards float; list rows cascade in after the podium; rings sweep in via `@property --sweep`. The board is keyed by period, so each switch replays the deal. Own `--o-*` palette: dark in Obsidian/Navy; Moonstone (`[data-theme="light"]`, `app/globals.css:610`) maps `--o-*` onto theme tokens and re-inks the card faces/backs, cone, flare, sheen, rays and embers in violet/gold on pearl.
- `app/lib/mockPosts.ts` — hardcoded `GLOBAL_POSTS`/`EXCLUSIVE_POSTS` arrays, no database table. `Post.call`/`.rank`/`.kind`/`.streakStat`/`.image`/`.market` are display-only fields with no backing computation — `PostImage` (`"chart"` sparkline or `"meme"` gradient+emoji tile, rendered by the `PostImage` component in `app/PostCard.tsx`) is placeholder art standing in for a real image upload. `Post.market` is a manually-tagged community label used only by non-`call` posts (e.g. `g7`, `g8`, `g-streak1`) — a `call` post's community is implied by `call.market` instead; both feed `FeedSwitcher`'s community dropdown. `FOLLOWED_HANDLES` backs the `FeedSwitcher` "Following" filter only, not a real social graph. The `g-streak1` mock post now reads as a daily BTC-call streak (consecutive-day count) rather than a same-day win streak — no daily-prediction mechanic backs it (see [roadmap.md](roadmap.md) "Not built"). `Post.flair` (`forYou`/`engaging`/`copying`/`followed`) and `MarketCall.copiedBy` are hand-assigned display-only fields — no engagement/recommendation signal or copy-trade action backs them; `copiedBy` is picked to scale with rank (Oracle `g-oracle1` 18.4k, Diamond `g-diamond1` 7.2k). `POST_REPLIES: Record<Post['id'], Reply[]>` backs `app/PostCard.tsx`'s reply thread — hand-written, not derived from `Post.replies` (that count is still just decorative), covers most non-streak/promo posts; posts without an entry render the thread's empty state. `Post.reposts` is a display-only count. `kind: "clash"` posts carry `Post.clash` (`Clash`/`ClashSide` `:64`, two sides with hand-picked crowd `share`s); `g-clash1` is the only one. `LIVE_CALL_COUNT` (`:98`) is a hardcoded rail number, not derived. `n1`–`n6` are trade-free opinion posts on generic market news (rate decision, exchange outage, ETF flows, stablecoin supply, Pulse, bridge exploit) interleaved with the calls; `n1`/`n2`/`n4` have `POST_REPLIES` threads. `MarketCall` carries `target`, optional `stop`, and `windowMin` (live calls) for the track/ring; ROI is derived from `entryPrice`/`currentPrice` (no `changePct`/`spark` on calls any more). `ClashSide.votes` replaces the old `share`. `GLOBAL_POSTS` is hand-ordered for a mixed top (trade → gossip → trade → clash → gossip → trade → news …) and re-timestamped to match; `gs1`–`gs5` are gossip/opinion posts, `t-near`/`t-liq`/`t-broken` are example doom / liquidated / broken calls, `g-clash2` a second (ETH) clash.
- `app/lib/rank.ts` — hardcoded `MOCK_CURRENT_RANK`/`MOCK_RANK_THRESHOLD` stub with `isExclusiveUnlocked()`, but `app/exclusive/page.tsx` doesn't call it right now — the gate (locked teaser + blurred preview) is temporarily disabled while iterating on the feed look, so `/exclusive` always renders the real list. No rank system exists anywhere else in the app (see [roadmap.md](roadmap.md) "Not built") — `Post.rank` strings in mock data are unrelated hardcoded labels, not derived from this stub.
- `PostCard` splits blank-line-separated text content into separate paragraphs for long-form takes. Content over 220 chars starts collapsed (`.post-content.is-collapsed`: 5 lines at every width, 7 at ≤768px) with a `.post-read-more` Read more/Show less toggle.
- Identity: mock posts use plain strings, not wired to Clerk. A future posting pass should use Clerk identity for authorship (persistent visible name/handle), not the anonymous `app/lib/playerId.ts` id used for matchmaking.
- Layout: `.feed-shell` is a two-column grid (`app/globals.css`) — feed column + sticky `.feed-sidebar`; `/` adds `.feed-shell--nav` for a three-column `200px | feed | 340px` grid (`180px | feed | 280px` at 961–1180px) with the `.feed-nav` rail, max width `var(--shell-max)` (1220px, shared with `.app-header`/`.lobby-shell`/`.wallet-shell`), collapsing to one column under 960px. Above 960px `.feed-sidebar` is sticky with `max-height: calc(100vh - 48px)` and scrolls itself when taller than the viewport. Posts are flat rows inside one bordered `.feed-panel` (hairline `border-top` between rows, `.feed-list > * + *`), also used for `/exclusive` and the profile Omens tab; `.feed-panel`/`.feed-nav` set `min-width: 0` so the scrolling chip/pill rows can't widen the grid column on phones. On phones, the shell uses 16px page gutters and leaves room for the fixed safe-area-aware bottom nav.

Rows have no rank outline/glow: Gold/Diamond get a tier avatar ring, Oracle a ring + glow; the trade card border shows call state, not rank. Gold+ `.rank-badge`s are animated: metallic fill + a `rank-sheen` sweep (`::after`, z-index -1 inside the isolated badge so it passes behind the text; 3.6s Gold / 2.8s Diamond / 2.4s Oracle), Diamond's `◆` twinkles, Oracle's fill drifts (`rank-holo`) with a pulsing glow and a spinning `✦`. Badges render through `app/RankBadge.tsx`, which puts `data-rank` on the badge itself (badge CSS is `.rank-badge[data-rank=…]`, not scoped to `.post-card`, so it also works on `/profile`; base `.rank-badge` is `inline-block` so `overflow: hidden` clips the sheen inline too) and sets `--shine-delay` from `hueFromHandle` (`app/lib/avatar.ts`) so same-tier sweeps don't sync. All of it stops under `prefers-reduced-motion`. `.market-call` (and `.post-image--chart`'s fill) use `--hud-*`. `.rank-badge` is a small uppercase mono tag (4px radius).
