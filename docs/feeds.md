# feeds

Twitter-styled social feeds. UI-only pass: no backend, no persistence, no posting.

- Routes: `/` = Global feed (`app/page.tsx`), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`, no longer linked from the header nav), `/rooms` = rank-gated group chat placeholder (`app/rooms/page.tsx`, see [rooms.md](rooms.md)), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)).
- `app/TabNav.tsx` — compact `Omens`/`Rooms` text-tab switcher rendered inside `app/layout.tsx`'s header (next to the brand), active tab via `usePathname()` (exact match on `/`, prefix match on `/rooms`), with a sliding underline (`main-nav-underline`) measured off the active link's `offsetLeft`/`offsetWidth`. `/duel` is a separate primary `Arena` CTA (icon from `app/icons.tsx`) in the header's `.header-actions`, not a nav tab.
- `app/PostCard.tsx` — client component (`useState` for the reply toggle below); shared post rendering, branches on `Post.kind`: `"text"` is a plain take (optionally with a `Post.image`, see below); `"call"`/`"result"` render a gradient identicon avatar, quiet rank badge, and a `MarketCallCard` hero (market symbol, side/leverage, sparkline for resolved calls, inline `↗ Copy trade` control for unresolved calls, entry→current price, outcome badge for `"result"` — WON/LOST with a $ amount, or a "close" miss string — and, for an unresolved call, `call.expiresIn` as "resolves in …"); `"streak"` renders a compact highlighted banner (no avatar/body layout); `"promo"` renders a quiet single-line system banner (no avatar, no actions). Non-streak/promo posts end in a ♡ like / Reply count actions row; `Challenge` (Arena's own action, not a real handler yet; icon from `app/icons.tsx`) moved off that row into `app/PostMenu.tsx`, a client-side ⋯ dropdown rendered in the meta row's trailing group (`.post-meta-trail`, alongside the rank badge). The Reply action is a button (`aria-expanded`) that toggles an inline `ReplyThread` (Reddit-style expand-in-place, not a TikTok overlay) rendered under `.post-actions`, reading `POST_REPLIES[post.id]` — shows the first 2 loaded replies, "view N more" reveals the rest of that same local array (no fetch, no backend). Posts with no `POST_REPLIES` entry show a muted empty state instead.
- `app/FeedSwitcher.tsx` — client component on `/` only; also owns the `feed-heading` section (moved out of `app/page.tsx` so the community dropdown can sit inline with the "Omens" `h1`). Local `useState` filter (`For You` / `Following` / `Live Calls`) over the posts passed in — `Following` matches `Post.handle` against `FOLLOWED_HANDLES`, `Live Calls` filters `kind === "call"` (pending/unresolved calls only) — combined with a second `useState` community filter, a `.community-dropdown` (`All` / `BTC` / `ETH` / `DOGE`) in the top-right corner of `.feed-heading-row` next to the title, blur-to-close like `app/PostMenu.tsx`, matching `post.market ?? post.call?.market`. No persistence, resets on reload. The old "N online · N arenas live" pulse strip (`LIVE_PLAYER_COUNT`/`LIVE_DUEL_COUNT`) was removed from `app/page.tsx` in favor of the community dropdown.
- `app/FeedSidebar.tsx` — persistent right rail (`Leaderboard` / `Most Profitable Calls` / `Trending Prophecie`), rendered on both `/` and `/exclusive` via the `.feed-shell` two-column grid; reads `app/lib/sidebarMocks.ts` (`LIVE_ARENAS`/`TRENDING_CALLS` are still independent mock data, but `TRENDING_PROPHECIES` pulls real entries out of `mockPosts.ts`'s `GLOBAL_POSTS` by id (`TRENDING_PROPHECY_IDS`) so "Trending Prophecie" shows actual post content instead of a synthetic leaderboard).
- `app/lib/mockPosts.ts` — hardcoded `GLOBAL_POSTS`/`EXCLUSIVE_POSTS` arrays, no database table. `Post.call`/`.rank`/`.kind`/`.streakStat`/`.image`/`.market` are display-only fields with no backing computation — `PostImage` (`"chart"` sparkline or `"meme"` gradient+emoji tile, rendered by the `PostImage` component in `app/PostCard.tsx`) is placeholder art standing in for a real image upload. `Post.market` is a manually-tagged community label used only by non-`call` posts (e.g. `g7`, `g8`, `g-streak1`) — a `call` post's community is implied by `call.market` instead; both feed `FeedSwitcher`'s community dropdown. `FOLLOWED_HANDLES` backs the `FeedSwitcher` "Following" filter only, not a real social graph. The `g-streak1` mock post now reads as a daily BTC-call streak (consecutive-day count) rather than a same-day win streak — no daily-prediction mechanic backs it (see [roadmap.md](roadmap.md) "Not built"). `POST_REPLIES: Record<Post['id'], Reply[]>` backs `app/PostCard.tsx`'s reply thread — hand-written, not derived from `Post.replies` (that count is still just decorative), covers most non-streak/promo posts; posts without an entry render the thread's empty state.
- `app/lib/rank.ts` — hardcoded `MOCK_CURRENT_RANK`/`MOCK_RANK_THRESHOLD` stub with `isExclusiveUnlocked()`, but `app/exclusive/page.tsx` doesn't call it right now — the gate (locked teaser + blurred preview) is temporarily disabled while iterating on the feed look, so `/exclusive` always renders the real list. No rank system exists anywhere else in the app (see [roadmap.md](roadmap.md) "Not built") — `Post.rank` strings in mock data are unrelated hardcoded labels, not derived from this stub.
- `PostCard` splits blank-line-separated text content into separate paragraphs for long-form takes.
- Identity: mock posts use plain strings, not wired to Clerk. A future posting pass should use Clerk identity for authorship (persistent visible name/handle), not the anonymous `app/lib/playerId.ts` id used for matchmaking.
- Layout: `.feed-shell` is a two-column grid (`app/globals.css`) — feed column + sticky `.feed-sidebar`, max width 1080px (matches `.lobby-shell`), collapsing to one column under 960px.
- CSS: `.header-left`/`.main-nav`/`.main-nav-link`/`.main-nav-underline`, `.arena-cta`, `.feed-shell`/`.feed-main`/`.feed-sidebar`/`.feed-heading-row`/`.community-dropdown`/`.community-dropdown-trigger`/`.community-dropdown-menu`/`.feed-tabs`/`.feed-list`/`.post-card`, `.market-call`/`.call-spark`/`.call-outcome`/`.call-expiry`, `.post-image`/`.post-image--chart`/`.post-image--meme`, `.post-card--streak`/`.post-card--promo`, `.rank-badge`/`.post-meta-trail`/`.post-menu`/`.post-menu-trigger`/`.post-menu-dropdown`/`.post-actions`/`.action-reply`/`.action-reply-caret`, `.reply-thread`/`.reply-thread-empty`/`.reply-item`/`.reply-avatar`/`.reply-body`/`.reply-meta`/`.reply-content`/`.reply-actions`/`.reply-thread-more`, `.sidebar-panel`/`.sidebar-row`, `.locked-teaser`/`.locked-preview` in `app/globals.css`, all resolving through the existing theme CSS variables.
