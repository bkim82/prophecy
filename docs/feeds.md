# feeds

Twitter-styled social feeds. UI-only pass: no backend, no persistence, no posting.

- Routes: `/` = Global feed (`app/page.tsx`), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`, no longer linked from the header nav), `/sanctum` = Oracle Room live Pulse room (`app/sanctum/page.tsx`, see [sanctum.md](sanctum.md)), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)).
- Desktop header (`app/layout.tsx`) is a 64px, 3-column grid: brand | `app/TabNav.tsx` | `.header-actions` (`app/BalancePill.tsx` + `app/AccountMenu.tsx`). `.app-header-inner` uses the page shells' width rule (`min(100% - 56px, --shell-max)`) so header edges align with content.
- `app/TabNav.tsx` — desktop `Omens`/`Arena`/`Sanctum`/`Wallet` (same order/icons as `app/MobileBottomNav.tsx`), active via `usePathname()` (exact on `/`, prefix otherwise), active = teal text + `--brand` 12% background. 769–1000px drops the icons.
- `app/BalancePill.tsx` — signed-in only; ember icon + Embers count button, dropdown (`.balance-menu-popover`) lists Embers + wallet USD + link to `/wallet`.
- `app/AccountMenu.tsx` — signed in: Clerk `UserButton` with a Light/Dark mode `UserButton.Action` (`useTheme()` from `app/ThemeToggle.tsx`); signed out: standalone `ThemeToggle` + Sign in. `compact` prop = mobile avatar-style sign-in.
- `app/MobileBottomNav.tsx` replaces the header nav at or below 768px; the compact mobile header keeps brand, `BalancePill`, `AccountMenu compact`.
- `app/PostCard.tsx` — client component (`useState` for the reply toggle and a local `liked` toggle below); shared post rendering, branches on `Post.kind`: `"text"` is a plain take (optionally with a `Post.image`, see below); `"call"`/`"result"` render a gradient identicon avatar, quiet rank badge, and a `MarketCallCard` hero (market symbol, side/leverage, sparkline for resolved calls, inline `↗ Copy trade` control for unresolved calls, entry→current price, outcome badge for `"result"` — WON/LOST with a $ amount, or a "close" miss string — and, for an unresolved call, `call.expiresIn` as "resolves in …"); `"streak"` renders a compact highlighted banner (no avatar/body layout); `"promo"` renders a quiet single-line system banner (no avatar, no actions). Non-streak/promo posts end in a `.post-actions` row of two real buttons: `.action-like` (client-only optimistic toggle, ♡→♥ + count, no persistence) and `.action-reply`; `Challenge` (Arena's own action, not a real handler yet; icon from `app/icons.tsx`) moved off that row into `app/PostMenu.tsx`, a client-side ⋯ dropdown rendered in the meta row's trailing group (`.post-meta-trail`, alongside the rank badge). The Reply action is a button (`aria-expanded`) that toggles an inline `ReplyThread` (Reddit-style expand-in-place, not a TikTok overlay) rendered under `.post-actions`, reading `POST_REPLIES[post.id]` — shows the first 2 loaded replies, "view N more" reveals the rest of that same local array (no fetch, no backend); each `ReplyItem` has its own local `liked` toggle too. Posts with no `POST_REPLIES` entry show a muted empty state instead.
- `app/FeedSwitcher.tsx` — client component on `/` only; also owns the `feed-heading` section (moved out of `app/page.tsx`); it has no title `h1` — just the community dropdown, left-aligned via `.feed-heading-row` `justify-content: flex-start` (compact 30px pill; `.feed-heading` bottom margin trimmed to 10px above 960px so the first post sits higher). Local `useState` filter (`For You` / `Following` / `Live Calls`) over the posts passed in — `Following` matches `Post.handle` against `FOLLOWED_HANDLES`, `Live Calls` filters `kind === "call"` (pending/unresolved calls only) — combined with a second `useState` community filter, a `.community-dropdown` (`All` / `BTC` / `ETH` / `DOGE`; trigger reads `Topics` while `All` is selected, else the selected market) in the top-left corner of `.feed-heading-row`, menu opening left-anchored, blur-to-close like `app/PostMenu.tsx`, matching `post.market ?? post.call?.market`. The filter tabs render in a `.feed-nav` left rail (Reddit-sidebar style: `Feeds` label, vertical icon+label rows from `app/icons.tsx` `ForYouIcon`/`FollowingIcon`/`LiveCallsIcon`, sticky, border-right) as the first column of `.feed-shell--nav` (`app/page.tsx`); `FeedSwitcher` now renders `.feed-nav` + `.feed-main` itself. At or below 960px the rail reverts to the `.feed-tabs` pill row under the heading (`.feed-main` gets `display: contents` + `order`). No persistence, resets on reload. At or below 768px the heading/filter controls use the phone spacing and the tabs become a full-width segmented control. The old "N online · N arenas live" pulse strip (`LIVE_PLAYER_COUNT`/`LIVE_DUEL_COUNT`) was removed from `app/page.tsx` in favor of the community dropdown.
- `app/FeedSidebar.tsx` — persistent right rail (`The Oracles` / `Most Profitable Calls` / `Trending Prophecie`), rendered on both `/` and `/exclusive` via the `.feed-shell` two-column grid; all three read `app/lib/sidebarMocks.ts` (`TOP_TRADERS`/`TRENDING_CALLS` are still independent mock data, but `TRENDING_PROPHECIES` pulls real entries out of `mockPosts.ts`'s `GLOBAL_POSTS` by id (`TRENDING_PROPHECY_IDS`) so "Trending Prophecie" shows actual post content instead of a synthetic leaderboard).
- `app/OraclesLeaderboard.tsx` — client component; the first rail panel, "The Oracles", as a tarot spread. Header has a `24H`/`7D`/`ALL` toggle (`useState`, default `7d`) over `TOP_TRADERS[period]` (`app/lib/sidebarMocks.ts`: hand-ordered per period, rank = position; `TopTrader` = handle + `tier` label + `winRate`). Ranks I–III are podium cards (DOM order I/II/III, CSS `order` lays out II · I · III, rank I taller) with Roman numeral, avatar initial in a win-rate ring (green arc = `winRate`, rest red) over a sunburst, handle, tier footer; ranks IV–V are rows (Roman rank, ringed avatar, handle, tier). No score/percentage shown. `View full leaderboard` button (after rank V) expands the list inline to all 10 mock traders (no separate page); switching period collapses it. Animation (CSS only, off under `prefers-reduced-motion`): cards rise face-down and flip III → II → I, rank I flares, a light cone opens over it, its sheen sweeps and aura pulses; rays spin, corner ✦ twinkle, embers rise, cards float; list rows cascade in after the podium; rings sweep in via `@property --sweep`. The board is keyed by period, so each switch replays the deal. Panel stays dark in both themes (own `--o-*` palette).
- `app/lib/mockPosts.ts` — hardcoded `GLOBAL_POSTS`/`EXCLUSIVE_POSTS` arrays, no database table. `Post.call`/`.rank`/`.kind`/`.streakStat`/`.image`/`.market` are display-only fields with no backing computation — `PostImage` (`"chart"` sparkline or `"meme"` gradient+emoji tile, rendered by the `PostImage` component in `app/PostCard.tsx`) is placeholder art standing in for a real image upload. `Post.market` is a manually-tagged community label used only by non-`call` posts (e.g. `g7`, `g8`, `g-streak1`) — a `call` post's community is implied by `call.market` instead; both feed `FeedSwitcher`'s community dropdown. `FOLLOWED_HANDLES` backs the `FeedSwitcher` "Following" filter only, not a real social graph. The `g-streak1` mock post now reads as a daily BTC-call streak (consecutive-day count) rather than a same-day win streak — no daily-prediction mechanic backs it (see [roadmap.md](roadmap.md) "Not built"). `Post.flair` (`forYou`/`engaging`/`copying`/`followed`) and `MarketCall.copiedBy` are hand-assigned display-only fields — no engagement/recommendation signal or copy-trade action backs them; `copiedBy` is picked to scale with rank (Oracle `g-oracle1` 18.4k, Diamond `g-diamond1` 7.2k). `POST_REPLIES: Record<Post['id'], Reply[]>` backs `app/PostCard.tsx`'s reply thread — hand-written, not derived from `Post.replies` (that count is still just decorative), covers most non-streak/promo posts; posts without an entry render the thread's empty state.
- `app/lib/rank.ts` — hardcoded `MOCK_CURRENT_RANK`/`MOCK_RANK_THRESHOLD` stub with `isExclusiveUnlocked()`, but `app/exclusive/page.tsx` doesn't call it right now — the gate (locked teaser + blurred preview) is temporarily disabled while iterating on the feed look, so `/exclusive` always renders the real list. No rank system exists anywhere else in the app (see [roadmap.md](roadmap.md) "Not built") — `Post.rank` strings in mock data are unrelated hardcoded labels, not derived from this stub.
- `PostCard` splits blank-line-separated text content into separate paragraphs for long-form takes. Content over 220 chars starts collapsed (`.post-content.is-collapsed`: 5 lines at every width, 7 at ≤768px) with a `.post-read-more` Read more/Show less toggle.
- Identity: mock posts use plain strings, not wired to Clerk. A future posting pass should use Clerk identity for authorship (persistent visible name/handle), not the anonymous `app/lib/playerId.ts` id used for matchmaking.
- Layout: `.feed-shell` is a two-column grid (`app/globals.css`) — feed column + sticky `.feed-sidebar`; `/` adds `.feed-shell--nav` for a three-column `200px | feed | 340px` grid (`180px | feed | 280px` at 961–1180px) with the `.feed-nav` rail, max width `var(--shell-max)` (1220px, shared with `.app-header`/`.lobby-shell`/`.wallet-shell`), collapsing to one column under 960px. Above 960px `.feed-sidebar` is sticky with `max-height: calc(100vh - 48px)` and scrolls itself when taller than the viewport. Each `.post-card` is its own bordered/radius block (not a border-bottom row list) for spacing and separation. On phones, the shell uses 16px page gutters and leaves room for the fixed safe-area-aware bottom nav.
- CSS: `.main-nav`/`.main-nav-link`/`.main-nav-icon`, `.balance-menu`/`.balance-display`/`.balance-menu-popover`, `.account-signed-out`, `.desktop-header-content`/`.mobile-header-content`/`.mobile-bottom-nav`, `.feed-shell`/`.feed-main`/`.feed-sidebar`/`.feed-heading-row`/`.community-dropdown`/`.community-dropdown-trigger`/`.community-dropdown-menu`/`.feed-tabs`/`.feed-shell--nav`/`.feed-nav`/`.feed-nav-label`/`.feed-nav-icon`/`.feed-list`/`.post-card`/`.post-read-more`, `.market-call`/`.call-spark`/`.call-outcome`/`.call-expiry`, `.post-image`/`.post-image--chart`/`.post-image--meme`, `.post-card--streak`/`.post-card--promo`, `.rank-badge`/`.post-meta-trail`/`.post-menu`/`.post-menu-trigger`/`.post-menu-dropdown`/`.post-actions`/`.action-reply`/`.action-reply-caret`, `.reply-thread`/`.reply-thread-empty`/`.reply-item`/`.reply-avatar`/`.reply-body`/`.reply-meta`/`.reply-content`/`.reply-actions`/`.reply-thread-more`, `.sidebar-panel`/`.sidebar-row`, `.oracles-panel`/`.oracles-head`/`.oracles-periods`/`.oracles-stage`/`.oracles-podium`/`.oracle-card`/`.oracle-card-flip`/`.oracle-card-face`/`.oracle-card-back`/`.oracle-avatar`/`.oracle-rays`/`.oracles-list`/`.oracle-row`/`.oracles-more` (The Oracles leaderboard, own `--o-*` palette, spans the full row at or below 960px), `.locked-teaser`/`.locked-preview` in `app/globals.css`, all resolving through the existing theme CSS variables. `.post-card` is a translucent glass panel (`--glass-*` tokens, both themes); no `backdrop-filter`, so `.post-menu-dropdown` isn't trapped under the next card. `PostCard` sets `data-rank` (`rankTier()` in `app/PostCard.tsx`: first word of `Post.rank`, typed as local `RankTier` — `roomsMocks.ts` no longer exports `RoomId`), and the Rooms tier tokens (`--room`/`--room-strong`/`--room-glow`) key off `data-rank` as well as `data-room`, so outlines + `.rank-badge` take the tier color. Gold/Diamond add glow, avatar ring, and a `--rank-tint` background layer; Oracle adds edge stars and a breathing `::after` glow. Gold+ `.rank-badge`s are animated: metallic fill + a `rank-sheen` sweep (`::after`, z-index -1 inside the isolated badge so it passes behind the text; 3.6s Gold / 2.8s Diamond / 2.4s Oracle), Diamond's `◆` twinkles, Oracle's fill drifts (`rank-holo`) with a pulsing glow and a spinning `✦`. `PostCard` sets `--shine-delay` per post (from `hueFromHandle`) so same-tier sweeps don't sync. All of it stops under `prefers-reduced-motion`. Diamond/Oracle recolor the trade card via `--hud-edge`/`--hud-grid`. `.market-call` (and `.post-image--chart`'s fill) use `--hud-*`; `.market-call::before` is a 12px HUD grid fading out to the right. `.post-flair` pill renders `FLAIRS[post.flair]`. Unresolved calls get `.market-call--open`: a second grid column pins `.market-call-copy-wrap` to the card's top-right (Copy trade, with `.market-call-copiers` — avatar stack + compact count — right-aligned under it; count text wraps to two lines ≤768px).
