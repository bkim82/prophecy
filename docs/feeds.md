# feeds

Twitter-styled social feeds. UI-only pass: no backend, no persistence; the composer posts locally only.

- Routes: `/` = Global feed (`app/page.tsx`), `/post/[id]` = single post + replies (`app/post/[id]/page.tsx`, 404 for unknown ids incl. composer posts), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`, no longer linked from the header nav), `/sanctum` = Oracle Room live Pulse room (`app/sanctum/page.tsx`, see [sanctum.md](sanctum.md)), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)).
- Desktop header (`app/layout.tsx`) is a 64px, 3-column grid: brand | `app/TabNav.tsx` | `.header-actions` (`app/ThemeToggle.tsx` + `app/BalancePill.tsx` + `app/AccountMenu.tsx`). `.app-header-inner` uses the page shells' width rule (`min(100% - 56px, --shell-max)`) so header edges align with content.
- `app/TabNav.tsx` — desktop `Omens`/`Arena`/`Sanctum`/`Wallet` (same order/icons as `app/MobileBottomNav.tsx`), active via `usePathname()` (exact on `/`, prefix otherwise), active = teal text + `--brand` 12% background. 769–1000px drops the icons.
- `app/BalancePill.tsx` — signed-in only; ember icon + Embers count button, dropdown (`.balance-menu-popover`) lists Embers + wallet USD + link to `/wallet`.
- `app/ThemeToggle.tsx` — top-right theme picker, signed in or out, desktop + mobile headers: swatch button → `.theme-menu-popover` with Obsidian (default, black + violet) / Navy (the original navy + teal feed) / Moonstone (light: pearl surfaces, white header, violet brand; id `light`) (`THEMES` in `app/theme.ts`). The old warm-sand light theme is gone. See [architecture.md](architecture.md) Theming.
- `app/AccountMenu.tsx` — signed in: Clerk `UserButton` with a Profile link (→ own `/profile`, see [profiles.md](profiles.md)) before Manage account, no theme action; signed out: Sign in. `compact` prop = mobile avatar-style sign-in.
- `app/MobileBottomNav.tsx` replaces the header nav at or below 768px; the compact mobile header keeps brand, `ThemeToggle`, `BalancePill`, `AccountMenu compact`.
- `app/MobileChromeAutoHide.tsx` (≤768px): scrolling down past 60px sets `html[data-chrome="hidden"]`, sliding the header up and bottom nav down; any scroll up, the top 60px, or a route change shows them again. `QuickTicketBar`/`ActiveMatchBar` drop 70px into the freed slot; keyboard focus (`:focus-visible`) holds a bar in view. CSS at the end of the 768px block in `app/globals.css`.
- `app/PostCard.tsx` — client component; flat row: avatar → meta (`AuthorLink` name, `RankBadge` right after it, `@handle · time`, then right-aligned flair tag + `PostMenu` ⋯) → content → `PostMedia` (`:450`) / `MarketCallCard` → actions → optional `footer`. Optional `context` (`:403`) renders a full-width `.post-context` line above the row (`.post-card--context` wraps the flex row); FeedSwitcher uses `context`/`footer` for the For You covers. Clicking a row's background (`openPost` `:389`, skips links/buttons/inputs/menus and text selections; ⌘/Ctrl-click opens a new tab) goes to `postHref()` (`:317`, `/post/<id>`, none for `local-` composer posts); the timestamp is the keyboard-accessible `.post-time` link to it; `.is-linkable` rows get a hover tint. This applies everywhere `PostCard` renders (feed, `/exclusive`, profile Omens tab). `detail` = the post-page layout (`.post-card--detail`: avatar + name row, then full-width text at 18px, never collapsed, a `.post-detail-meta` line with time + topic pills, no inline thread); `onReply` replaces the inline-thread toggle (post page focuses its reply box); `onNotInterested` adds "Not interested in <topic>" items (one per `postTopics()` topic) to `PostMenu`. Author name (`app/AuthorLink.tsx`) and avatar (`:406`, mouse-only duplicate: `tabIndex=-1`, `aria-hidden`) link to `/profile/[handle]` when `profileHref()` finds a mock profile, see [profiles.md](profiles.md). Every row has `id="post-<id>"` (call-strip anchors). Branches on `Post.kind`: `"streak"` banner row, `"promo"` quiet system line, `"clash"` → `ClashCard` (`:264`: eyebrow with `ClashIcon` + total votes, `Nova ↑ 69.5k vs ↓ 67.6k Vesper`, crowd split bar, two "Side with …" buttons; voting adds one local vote to that side and recomputes split/bar/total, the pressed side reads "✓ Sided with …", click again to switch or take it back — nothing persists or settles), else the standard row. Flair = short tag (`FLAIRS` `:21`: For you / Hot / Rising / Followed, full sentence as `title`). Actions row (`:463`), in order: like (`HeartIcon`, fills + pops when liked), comment (`CommentIcon`, toggles the inline `ReplyThread`), vouch (`VouchIcon`), defy (`DefyIcon`) — local optimistic toggles, nothing persists, counts compact (`1.3k`) — then a right-aligned `.action-bookmark` (`BookmarkIcon`, filled when saved; persisted via `app/lib/postLists.ts`). Buttons are 36px tinted pills with 19px icons (34px/17px, tighter padding ≤420px so all five fit), each tinting to its own `--tone` on hover/active: like `--like` (pink, new theme token), comment brand, vouch `--chart-up`, defy `--negative`. Vouch/Defy show a word label until the row (a size container) is ≤470px wide, and carry `title` tooltips. Vouch and Defy are both plain one-tap reposts (no stake, no note): Vouch = repost to your followers as one you back, Defy = as one you're against. They share one `reshared` state, so a post is vouched or defied, not both (pressing the other switches, pressing the active one undoes); the active one adds +1 to its count and turns the row into a reshare headed "You vouched for this omen" / "You defied this omen" · now. The `share` prop (a followed account's vouch/defy from FeedSwitcher) does the same with their avatar + linked name; your own vouch/defy replaces it. A reshared row (`embedded`, not on the post page) is laid out like an X quote post: the `ReshareHead` row on top, then the original post (avatar, body, actions) inside a bordered `.post-reshare-embed` card indented to the sharer's text column (full width ≤768px), and a cover's `footer` moved below the card (`.post-reshare-footer`). On the post page the header just sits above the normal detail layout. `ReplyItem` (`:176`, exported for the post page) uses the same heart.

- `app/post/[id]/PostThread.tsx` — post page body: back button (`router.back()`, or `/` on a fresh tab) + "Post" title, then one `.feed-panel` with `PostCard detail`, a local-only `ReplyComposer` ("Replying to @handle" / "Post your reply", Clerk name like `FeedComposer`, prepends to this page's list, gone on reload) and every `POST_REPLIES` entry as a full `.post-replies` row (no "view more"). The comment action focuses the reply box.
- `MarketCallCard` (`app/PostCard.tsx:133`, exported for the profile Trades tab) — every call on one doom → destiny track. Pieces: `TimeRing` (`:65`, coin inside a ring that drains `expiresIn / windowMin`; full once resolved) │ asset + `↑LONG`/`↓SHORT` over `20x · 1h 55m left` / `closed` / `wiped` │ `CallTrackBar` (`:90`: left end = doom = whichever of `stop` / leverage liquidation price sits closer to entry, labelled `STOP`/`LIQ`; right end ✦ = `target`; glowing orb = current price; tick = cast/entry; the segment between tick and orb is the move so far) │ ROI hero (`callRoi()` = price move × leverage, flipped for shorts, floored at −100%) with a status label (`STATUS_LABEL` `:121`) │ open calls only: violet Copy (zigzag `TrendIcon`, not wired) with `TailingCount` under it (3 overlapping gradient circles + `18.4k tailing` from `copiedBy`). State comes from `callTrack()` (`app/lib/calls.ts:58`) and is set as `data-state`: `live` (violet glow, pulsing orb), `doom` (open with the orb in the first 15% of track, `DOOM_ZONE` `app/lib/calls.ts:32` — red pulse, "⚠ 0.3% to liq/stop"), `fulfilled` (`outcome.status "won"`, orb on ✦, all gold), `broken` (`"lost"`/`"close"`, grayscale + dimmed), `liquidated` (`"liquidated"`, red hazard stripes, −100%). Layout is a container query on `.market-call-frame`: ≥680px one row (profile Trades tab), default = track on its own row (feed), ≤420px adds an action row and lets the CAST label flow inline (phones). Prices format like the entry string (`formatCallPrice`).
- `app/FeedSwitcher.tsx` — client component on `/` only; renders the `.feed-nav` rail + `.feed-main` (one `.feed-panel`: `app/FeedComposer.tsx` → `MixBanner` → `TopicChips` → `InterestPicker` (open via `+`) → `TopicHeader` (topic view only) → `app/CallStrip.tsx` → `.feed-list`; pieces in `app/FeedTopics.tsx`). Rail filters (text only, `◆ Feeds` label): For You / Following (posts by `FOLLOWED_HANDLES` plus posts they vouched/defied — `FOLLOWED_SHARES` `:25`, latest share per post — sorted by `followingAge()` `:31`, i.e. when the post or its reshare hit the feed; every view passes that share to `PostCard` as its line) / Live Calls (`kind === "call"`, green dot + `LIVE_CALL_COUNT`) / Clashes (`kind === "clash"`) / Bookmarked (ids in `useBookmarks()`, feed order, own empty-state copy), combined with the topic chip row (`view` state: `forYou` or a `TopicId`; chips = `useInterests()` order, first chip reads `✦ For You` on the For You rail and `All` elsewhere, a just-unfollowed open topic keeps its chip; matches via `postTopics()`). The For You home (`home` `:63` = rail For You + chip For You) is personalized: `pickCovers()` (`:84`) puts one cover per interest on top, each a normal `PostCard` with `CoverEyebrow` ("Because you're interested in X") as `context` and `SeeMore` ("See more on X →", runs `openTopic` `:123`: switches chip + scrolls the panel top into view) as `footer`; then a `.feed-section-label` "More for you" and the rest via `personalize()`. `MixBanner` (home only, 2+ interests) toggles `mixed`: covers off, feed = `blendTopics()` round-robin. `TopicHeader` shows icon, kind, post count, a Not interested button and a Follow/Following toggle. `InterestPicker` lists muted topics under "Not interested · hidden from For You" (dashed chips, click to unmute); following a muted topic also unmutes it. No interests → `.feed-covers-empty` prompt opens the picker. `localPosts` state (`:54`) holds composer posts, pinned above the covers. "Not interested" (cover eyebrow `.cover-dismiss`, the ⋯ menu on any For You row, or the topic header) runs `notInterested()` (`:104`): `useMutedTopics().mute()` (unfollows + stores), drops back to For You if it was the open topic, and leaves a `MutedNotice` ("Got it. You won't get X suggestions…" + Undo) at the post's old row index — rows are built as post/label/notice items (`rows` `:92`), notices only show in the view they were made in. Undo (`:116`) unmutes and restores the topic at its old interests position. Muted topics' posts are dropped from the home suggestions (`suggestions` `:82`: covers, the feed under them, Mix it up) but not from the other rail feeds or topic views. Under the tabs, a border-top section break then `app/FeedNotifications.tsx` (`.feed-notifs` "Notifications", rail-only, hidden ≤960px; replaced the old Recently viewed list). At ≥961px the rail is capped at `100vh - 48px` and scrolls, so the list stays reachable while the rail is sticky. Composer posts, filter, topic chip and mix mode aren't persisted, reset on reload (interests are). ≤960px the rail becomes a horizontally scrolling pill row above the panel (`.feed-main` gets `display: contents` + `order`).
- `app/lib/topics.ts` — interest topics: `TOPICS` (`:37`, 20 across `TopicKind` currency (BTC/ETH/SOL) / coin (`$DOGE`/`$PEPE`/`$BONK`/`$WIF`/`$BRETT`/`$HYPE`) / company / person / theme, each with `glyph` + `color`, no brand logos; `short` = chip label), `TOPIC_KINDS`, `DEFAULT_INTERESTS` (`:71`, 2 currencies + 2 coins + company + 2 people + theme). `postTopics()` (`:79`) = `Post.topics` plus the asset implied by `market ?? call.market ?? clash.market`. Ranking is mock-only: `postScore` = log10(likes + 2·(vouches + defies) + 3·replies) − age/45min (age parsed from the `"2m ago"` strings); `coverOrder()` (`:112`) reorders interests to take turns by kind (kinds in first-followed order) so one kind can't stack at the top; `pickCovers()` (`:132`, coverOrder, hottest unused `text`/`call`/`result` post per topic, prefers an author without a cover yet, max 8); `personalize()` (`:156`, your-topic posts in feed order with one outside post after every 3); `blendTopics()` (`:169`, round-robin in coverOrder, your topics only).
- `app/PostMedia.tsx` — X-style media under a post (`Post.media`): one item full width, 2–4 in `.post-media--grid`. Each `PostImage` kind is a fake screenshot in HTML/SVG with its own fixed palette (reads as a pasted image in every theme), `role="img"` + `alt`: `candles` (exchange chart; seeded-noise candles around `path`, optional `level` line, `spike` wick, red marker `note` circle), `post` (screenshot of another account's post), `headline` (news article), `pnl` (Prophecy share card + decorative QR), `chat` (message thread), `orderbook` (wall row outlined + note; drops Total at phone width), `bars` (dashboard bars; negatives switch to green/red flows), `explorer` (block-explorer tx page), `meme` (gradient + emoji + optional Impact caption). Shots are size containers, tightening via `@container`.
