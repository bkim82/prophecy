# feeds

Twitter-styled social feeds. UI-only pass: no backend, no persistence, no posting.

- Routes: `/` = Global feed (`app/page.tsx`), `/exclusive` = rank-gated feed (`app/exclusive/page.tsx`), `/duel` = the market lobby (moved from `app/page.tsx`, see [architecture.md](architecture.md)).
- `app/TabNav.tsx` — persistent client-side tab switcher in `app/layout.tsx`, active tab via `usePathname()` (exact match on `/`, prefix match on `/duel` and `/exclusive` so nested duel routes still highlight "Duel").
- `app/PostCard.tsx` — shared post rendering, branches on `Post.kind`: `"text"` is a plain take (optionally with a `Post.image`, see below); `"call"`/`"result"` render a gradient identicon avatar, quiet rank badge, and a `MarketCallCard` hero (market symbol, side/leverage, sparkline, entry→current price, outcome badge for `"result"` — WON/LOST with a $ amount, or a "close" miss string — and, for an unresolved call, `call.expiresIn` as "⏳ resolves in …"); `"streak"` renders a compact highlighted banner (no avatar/body layout); `"promo"` renders a quiet single-line system banner (no avatar, no actions). Non-streak/promo posts end in a ♡ like / Reply count actions row; `⚔ Challenge` (Duel's own action, not a real handler yet) moved off that row into `app/PostMenu.tsx`, a client-side ⋯ dropdown rendered in the meta row's trailing group (`.post-meta-trail`, alongside the rank badge).
- `app/FeedSwitcher.tsx` — client component on `/` only; local `useState` filter (`For You` / `Following` / `Live Calls`) over the posts passed in — `Following` matches `Post.handle` against `FOLLOWED_HANDLES`, `Live Calls` filters `kind === "call"` (pending/unresolved calls only). No persistence, resets on reload.
- `app/FeedSidebar.tsx` — persistent right rail (`Live Duels` / `Trending Calls` / `Top Traders`), rendered on both `/` and `/exclusive` via the `.feed-shell` two-column grid; reads `app/lib/sidebarMocks.ts` (`LIVE_DUELS`/`TRENDING_CALLS`/`TOP_TRADERS`), independent of `mockPosts.ts`.
- `app/lib/mockPosts.ts` — hardcoded `GLOBAL_POSTS`/`EXCLUSIVE_POSTS` arrays, no database table. `Post.call`/`.rank`/`.kind`/`.streakStat`/`.image` are display-only fields with no backing computation — `PostImage` (`"chart"` sparkline or `"meme"` gradient+emoji tile, rendered by the `PostImage` component in `app/PostCard.tsx`) is placeholder art standing in for a real image upload. `LIVE_PLAYER_COUNT`/`LIVE_DUEL_COUNT` feed the feed's live pulse strip. `FOLLOWED_HANDLES` backs the `FeedSwitcher` "Following" filter only, not a real social graph. The `g-streak1` mock post now reads as a daily BTC-call streak (consecutive-day count) rather than a same-day win streak — no daily-prediction mechanic backs it (see [roadmap.md](roadmap.md) "Not built").
- `app/lib/rank.ts` — hardcoded `MOCK_CURRENT_RANK`/`MOCK_RANK_THRESHOLD` stub with `isExclusiveUnlocked()`, but `app/exclusive/page.tsx` doesn't call it right now — the gate (locked teaser + blurred preview) is temporarily disabled while iterating on the feed look, so `/exclusive` always renders the real list. No rank system exists anywhere else in the app (see [roadmap.md](roadmap.md) "Not built") — `Post.rank` strings in mock data are unrelated hardcoded labels, not derived from this stub.
- Identity: mock posts use plain strings, not wired to Clerk. A future posting pass should use Clerk identity for authorship (persistent visible name/handle), not the anonymous `app/lib/playerId.ts` id used for matchmaking.
- Layout: `.feed-shell` is a two-column grid (`app/globals.css`) — feed column + sticky `.feed-sidebar`, max width 1080px (matches `.lobby-shell`), collapsing to one column under 960px.
- CSS: `.tab-nav`/`.tab-switcher`, `.feed-shell`/`.feed-main`/`.feed-sidebar`/`.feed-tabs`/`.feed-pulse-strip`/`.feed-list`/`.post-card`, `.market-call`/`.call-spark`/`.call-outcome`/`.call-expiry`, `.post-image`/`.post-image--chart`/`.post-image--meme`, `.post-card--streak`/`.post-card--promo`, `.rank-badge`/`.post-meta-trail`/`.post-menu`/`.post-menu-trigger`/`.post-menu-dropdown`/`.post-actions`, `.sidebar-panel`/`.sidebar-row`, `.locked-teaser`/`.locked-preview` in `app/globals.css`, all resolving through the existing theme CSS variables.
