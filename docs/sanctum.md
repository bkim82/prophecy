# sanctum

`/sanctum` = the Oracle Room: a continuous real-money-style Pulse room for the user's own rank only. UI-only pass: live prices are real; no other players are connected (no simulated ones either), so the feed and chat hold only your own trades and messages; balance and settlement are client-side preview. See [roadmap.md](roadmap.md) "Not built".

- Route: `/sanctum` (`app/sanctum/page.tsx` -> `app/sanctum/SanctumView.tsx`, client), linked from the header and phone nav as "Sanctum" (`SanctumIcon` temple glyph, `app/icons.tsx`), between Arena and Wallet (`app/TabNav.tsx`, `app/MobileBottomNav.tsx`). Formerly Rooms: `/rooms` 307-redirects here (`next.config.ts`). Only the user's room is shown — no switcher, no other ranks. Rank is hardcoded Oracle (`ROOM.tier` in `app/lib/rooms.ts`); tier list `RANK_TIERS`/`RoomId`/`isRoomId` lives in `app/lib/rank.ts` (server-safe — `rooms.ts` calls a client fn at module load, so server code must not import it).
- Entry gate (`app/sanctum/SanctumGate.tsx`, mounted first in `SanctumView`): full-screen overlay: stone wall + arched doorway (`.sanctum-gate-way`, wall = 100vmax box-shadow) holding two 3D slab doors (face + `--door-depth` inner-edge slab) in the tier's material, tier sigil split across the seam. Latch jolt → doors swing out toward the viewer (`rotateY` ±80°) with seam light → view pushes through (scale + fade), then unmounts (~2.25s; click/Esc skips; 4s timer fallback). No `filter`/`overflow` on `.sanctum-door` — it would flatten the 3D. Plays on every visit. Per-tier: `EMBLEMS` (bronze shield, silver crescent, gold sun, platinum hex, diamond gem, prophet flame, oracle eye) + `--door-pattern` (studs+bands / brushed / lattice / vertical brushed / facets / rings / stars) in globals.css "Sanctum gate" block. Reduced motion: no swing, quick fade. `?rank=<tier>` previews another tier's gate (`app/sanctum/page.tsx` → `previewRank` prop); the room stays Oracle.
- Coins: `ROOM_COINS` = BTC, ETH, and the daily coin (`pickDailyCoin()`, `app/DailyCoin.tsx`). Picked from a `<details>` dropdown (`.oracle-coin-select`) at the top right of the chart, right of the price headline; each option shows its live price and a dot if you hold a position there. `SanctumView` runs one `usePriceFeed` per coin (3 sockets) so the dropdown, feed events, and positions in any coin all price live (`app/sanctum/SanctumView.tsx:60`).
- Chart: `PriceChart` for the selected coin, markers = every feed event in that coin, all yours (`owner: "you"`, solid, P&L toast) (`:139`, `app/PriceChart.tsx:14-24`).
- Trading: no rounds. One position per coin, stake presets + Max, 100/1000/10000× leverage, Close / Reverse. P&L = stake × move% × leverage floored at −stake; a position at −stake auto-closes (`:32`, `:93-134`). Balance = `PREVIEW_BALANCE` $1,000 (`:17`) tagged "Preview funds" when no wallet; nothing settles.
- Wallet: `useWalletAddress` (`:77`) reads `eth_accounts` (never prompts) + `accountsChanged`; connected shows `USD · 0x…` chip, otherwise a "Wallet not connected · Connect" link to `/wallet`. The room is fully usable either way.
- Room feed (`app/sanctum/RoomFeed.tsx`): newest-first tape of your opens/closes ("You longed $300 BTC @ price · 1000× · 12s"), filter chips All/BTC/ETH/daily (local state, independent of the chart's coin dropdown); empty → "The room is quiet. Watching for signs…".
- Mini chat (`app/sanctum/RoomChat.tsx`): "Whispers" panel in the left column, your local sends only (starts empty: "No whispers yet."; no online count), auto-scrolls, capped at 40.
- Theming (`app/globals.css`, "Oracle Room" block): `[data-room="oracle"]` sets `--room`/`--room-strong`/`--room-glow` (oracle violet; light overrides). Hero = animated `OracleSigil` eye, star dots, violet moon `::before`, rune band `::after`. Chart column is `.arena-shell[data-market]` so chart/dock borders take the coin's colour. Layout `.oracle-grid` areas: chat | chart | feed (Whispers on the left); ≤1180px the feed drops under the chart with chat still left; ≤760px one column chart → feed → chat. Chat and feed columns are sticky. `.oracle-quote` has `z-index: 5` so the coin menu paints over the chart (the `.arena-shell > *` entrance animation gives each child its own stacking context).
